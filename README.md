# NeoCare - Infant Cry Analysis System

## Overview
NeoCare is an AI-powered infant cry analysis system that classifies baby cries into different categories to help parents and caregivers understand an infant's needs.

## Problem Statement
Parents often struggle to identify why an infant is crying. NeoCare uses deep learning to classify cries into meaningful categories.

## Cry Categories
- Belly or Physical Pain
- Burping
- Discomfort
- Hungry
- Temperature Discomfort
- Tired
